# 🍽️ MessMate

MessMate is a modern and responsive **hostel mess management website** built using HTML, CSS, and JavaScript.

The project allows students to view daily and weekly mess menus, rate meals, and submit feedback through a simple and user-friendly interface.

## ✨ Features

- 📅 View today's mess menu
- 🍛 View complete weekly menu
- 🔄 Week 1 & 3 / Week 2 & 4 menu cycles
- ⭐ Rate meals
- 💬 Submit meal feedback
- 💾 Store feedback using LocalStorage
- 💻 Simple command system
- 🌙 Dark mode
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Google Fonts

⚠️ Project Note

This project was developed for learning and frontend development practice.

It is currently a frontend-only project, so features that normally require a backend, such as user authentication, cloud database storage, and centralized feedback management, are not implemented.

The feedback feature uses browser LocalStorage, so the data is stored locally in the user's browser and is not shared with other users.

A backend can be integrated in the future using technologies such as Node.js, Express, and MongoDB.
